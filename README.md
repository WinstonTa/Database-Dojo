# Database Dojo

A standalone React/Vite SQL learning app for CECS 323. The interactive PostgreSQL curriculum and practice engine are under active implementation.

## Local development

```bash
npm install
npm run dev
```

Build for Vercel: `npm run build`; the static output is `dist/`.

Archived previous Next.js website: `archive/pre-cecs323-react-2026-11-10`.
